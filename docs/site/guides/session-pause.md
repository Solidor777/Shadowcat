# Session pause

The GM can pause the session. A pause stops token movement and the combat clock for
players while everything else keeps working.

## Pausing and resuming

The GM has a toggle in the top bar: **Pause game** and **Resume game**. Pausing opens
a prompt for an optional note (at most 280 characters); cancelling leaves the session
running. An **Also pause audio** checkbox pauses the playing tracks too. The default
key is Alt+P and can be rebound ("Pause or resume the game").

Everyone sees a banner: "The game is paused", or "The game is paused: " followed by
the note.

## What a pause blocks for players

- Moving tokens, including choosing a portal destination.
- The combat clock: combat documents and the combat actions.

The stage and the combat tracker show a notice that explains it. A refused action
reports "The game is paused."

## What keeps working

Chat, dice, pings, doors, scene edits, sheets, notes, and the select and measure tools.
The GM is never refused.

## Audio

Resuming restarts only the tracks the pause stopped, not tracks the GM paused by hand.
